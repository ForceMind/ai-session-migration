# 0.3.0 预览版

新增图形化恢复中心：按会话、项目、应用资料、数据库、历史版本、快照、密钥和软件查看备份，按文件、文件夹或整组选择恢复。支持跨分卷/差异引用、分页搜索、缓存位置选择及空间不足保护。

恢复前先预览冲突、完整备份并回读目标；已有文件跳过。恢复记录支持复核和条件撤销，保留用户后续修改。原生会话继续使用 Claude Code、Codex、DeepSeek Harness 导入向导。原始会话与 thinking 不改写，历史命令不执行。

104 项测试已在本地、Linux、Windows 通过，两平台打包程序完成合成原生导入及文件恢复流程。构建源码为 `8aecbd045e45522be7eb07ef35eb873471407ddb`，后续主分支只增加网站及说明，保持应用源码一致；发布安装包保持已验收字节与 SHA-256。

# 会话与项目迁移实施方案

本方案以 0.3.1 本地候选版为开发基线，当前已生成 0.4.0 Windows x64 本地候选包及模型兼容修订。客户端沿用现有原生图形界面，源电脑和目标电脑的日常操作都可通过双击客户端完成。

## 实施记录

| --- | --- |
| 1 | 迁移 ZIP 与原样加密保全分别校验。合成账号字段、带前导空白的嵌套账号记录和继承日志核查通过，Codex 分页回读通过。账号检查命中可按会话或项目文件排除，再从同一份已验证的加密快照重建。重建逐次复核已识别账号值和凭据。GUI、批量计划以及旧侧栏入口拒绝 Claude 原生写入，文件恢复与导入备份保护默认及自定义客户端资料目录。 |

## 用户在两台电脑上的操作

**源电脑**　打开「新建导出」，扫描并勾选会话。下一页按实际工作目录列出项目、关联软件及会话数，每个项目只选一次处理方式。有 Claude 主会话时，预览现有接手稿、待生成稿和所用模型服务。选择移动硬盘目录，查看将携带的资料和估计大小，导出后逐项回读。

确认页列出每个项目选中的文件数和体积，并分别估算迁移包、加密保全、保存盘临时文件和缓存。若保存盘与缓存同盘，会合计需求。可以在设置中把缓存改到移动硬盘，随后重新扫描来源或打开迁移包。

**目标电脑**　从欢迎页点「从移动硬盘恢复」，选择备份总目录或迁移包。先选项目，可提取工作文件、从 Git 获取指定版本，或关联本机已有目录。再勾选 Codex、DSH 会话，预览冲突、备份目标、确认导入。Claude 条目直接打开原文和接手稿。结果页可复查新增、跳过、阻止、待补稿及对应原因。

冲突预览会列出目标暂存或新增文件、完整目标备份及所在盘的可用空间。同盘时会合计。执行前重新检查空间及目标状态，空间已不足时停在创建副本之前。

Windows 上若预览提示 DSH 暂存路径过长，为该会话改选较短的目标项目目录或 DSH 资料目录，再重新预览。

「从 Git 获取」会先展示已核对的提交和随包本地改动，确认后才写入新目标目录。提交无法获取时，可在同一窗口改选已有项目。Git LFS 内容和子模块可按预览提示使用目标机的仓库权限获取。

| 来源 | 迁移包中携带 | 目标电脑上的操作 |
| --- | --- | --- |
| Codex | 已处理账号数据的可迁移会话、必要的分页记录与附件、父子关系、项目引用 | 映射项目，在相容的本地库导入。已有会话 ID 跳过，缺正文、缺父记录和版本不兼容逐条显示。目标账号负责登录和续聊。 |
| DeepSeek Harness | 本地会话日志、所选附件、项目关联、归档及置顶信息 | 当前支持 v4 会话和 v2 工作区登记。导入后回读事件和附件，沿用目标机的账号、渠道与插件配置。其他已保存格式可归档和查看其可读内容。 |
| Claude Code | 本地保存的对话阅读版、原文定位、接手稿、项目引用 | 在迁移软件内浏览、搜索、复制。在新账号打开项目，新建会话，由用户粘贴并发送。Claude 原生会话导入、侧栏登记和账号索引重建均关闭。 |
| 项目文件 | 一个项目条目供三种软件的会话引用 | 项目可单独恢复。一个混合包可同时恢复项目和 Codex、DSH 会话，并在同一客户端阅读 Claude。 |

## 第一批先解决的两个问题

**统一 Claude 的写入边界。** 0.3.1 的「历史与接手」页是只读入口，通用导入器和 Windows 批量向导仍能写入 Claude。新版在创建计划和执行写入时都按软件自己的规则检查来源。混合包中只把 Codex、DSH 加入原生导入，Claude 进入阅读列表。旧包、已保存的计划、批量续跑和单独的 Claude 侧栏入口都执行同一规则。用户可查看旧回执。遇到旧版未完成的 Claude 写入，显示事务状态及备份位置，停止自动续写。项目文件恢复到用户选择的工作目录，拒绝把文件恢复目标指向客户端活动资料目录。

**在导出端处理 Codex 账号数据。** 合成导出已经证实，当前 ZIP 的会话目录和原生数据库行都可能保留源账号 ID。采用按记录类型定义的字段清单，在写入可迁移包前处理账号和组织归属、登录资料与凭据。覆盖会话目录、原生日志及继承段、分页数据库行、派生历史、清单和报告。保留恢复所需的会话、父子、项目和附件标识。日志字节长度变化时同步重算分页偏移和内容校验值。导入端再次校验包的用途、格式与允许字段。遇到账号或版本不相容的条目，界面说明原因并提供阅读入口。

私人原始保全与可迁移包分别生成。保全从只读快照保存来源原有的日志和已保存 thinking，按现有方式加密并解密回读。可迁移包从同一批快照生成经处理的记录。正文、附件或项目文件中手工写入的身份信息，单独列入内容检查。用户可以在迁移副本中处理命中项，也可以排除对应内容。无法核查的内容标明范围，导出报告只记位置、类别和数量。加密和脱敏各有自己的验收结果。

可迁移包以项目代号、相对路径和消息位置定位原文。清单需要保留的完整本机路径归入私人保全及本机映射，避免随包携带路径里的用户名或账号标识。封包后重新打开全部条目，检查已知账号字段及凭据。命中项显示在哪条记录、哪个字段，由用户处理或排除后重新校验。仍有命中时禁止将受影响包标为可原生迁移。

备份结果页可查看命中的类别、对象位置、记录行号和可定位的字段，报告保留位置与数量。项目文件可单独排除，会话正文、日志和附件按所属会话排除。从已通过回读的加密快照重建后，新迁移包单独保存并再次校验。原加密保全与其结果记录继续可用。

首批可操作结果是在图形界面打开一份三来源包，逐项看到「可原生导入」「只读接手」或具体阻止原因，并可导出和回读一条已脱敏的 Codex 会话。

## 共享项目与 Git 选择

一个会话引用一个项目条目和该项目内的相对工作目录。以经过核对的工作目录或 Git 工作树根识别项目，同一工作树下不同子目录保留各自的工作位置。多个软件引用同一项目时，在本次迁移包内只扫描和归档一份工作文件。不同检出目录、工作树和嵌套仓库分别列出，项目同名或远端相同均不足以合并。非 Git 项目支持手选根目录。允许短路径下明确选中的项目，盘根、用户主目录和导出目标继续受保护。

| 导出选择 | 源端保存 | 目标端处理 |
| --- | --- | --- |
| 随包带工作文件 | 保存选中文件、相对路径和哈希。预览列出未提交、未跟踪及排除项。过滤 `.git` 目录及工作树指针文件、独立凭据和依赖缓存。 | 先预览新增、已有相同和同名不同的文件，再写入新位置或补缺，已有不同内容保留并列出。 |
| 从 Git 获取 | 记录去凭据的远端地址、完整提交号、分支提示和子目录。展示工作区修改、删除、未跟踪文件，以及提交在远端的可得性。允许携带所选本地差异。 | 使用目标机自己的仓库权限，在新目录获取指定提交并核对版本，再预览本地差异。离线、无仓库权限、远端无法取得提交时，可改选已有目录或回源端带工作文件。 |
| 只关联或跳过项目文件 | 保存用于关联的项目标识和会话清单。 | 选择已有目录，或暂缓项目。会话原文仍可浏览，需要真实工作目录的原生导入项标为待映射。 |

Git 的本地差异需保留新增、修改和删除的语义，只对已核对基线的目标副本应用。远端可得性未验证时明确标示。未推送的提交若无法从远端取得，提示改用工作文件方案。有子模块或 Git LFS 时，将其本机可用内容和远端复原条件列入项目检查。

## Claude 阅读版与模型接手稿

从可读的 Claude 本地会话生成阅读版，也可接入已有的编号 Markdown 归档。原文、消息角色、物理行号、主会话与子代理关系、接手稿都通过包内相对引用关联。打开包时直接从本包读取。在只有迁移包的目标电脑上也能看全文并定位引用。

每份选中的主会话对应一份接手稿。首次接入旧 TSV 和单独补充的成稿时，使用已经核实的归档及编号映射建立来源指纹。之后按归档、会话和来源指纹核对并复用，防止不同归档的同编号串稿。原文变更时提示复核，重生成的版本供用户比较。子代理记录可阅读和按需引用。

打开迁移包后，Claude 会话列表会显示包内稿件状态。选定主会话后，可在接手稿页为该会话生成并比对新旧稿。生成前核对原文指纹，并确认实际接收服务。对照稿留在当前阅读窗口，可采用、编辑后复制，原包内的稿件继续可用。

| 生成方式 | 图形界面与执行行为 |
| --- | --- |
| 使用本机 Codex | 检测已安装的 Codex CLI，后台非交互运行，沿用用户选定的模型配置。界面显示实际服务位置，连接本机推理服务时标「本机推理」。在独立临时环境中处理指定文本，生成任务与正在进行的开发会话隔离。 |
| 使用自定义模型服务 | 填写服务地址、模型名和 API Key，选择服务支持的 OpenAI 兼容协议（Chat Completions 或 Responses）。支持本机地址。Key 仅供本次请求使用，连接测试使用合成短句。 |

在首次发送本批材料前，显示接收服务、模型和将发送的会话。默认只发送选中会话的可读对话文本和包内原文定位。附件、项目源码、凭据及原始 thinking 排除在默认模型输入之外。历史中的工具记录按文本处理，生成环境限制执行命令、访问项目和调用其他工具。目标是生成一份可编辑的交接文本，包括原目标、已完成事项及其依据、未证实的历史说法、停点、第一步和出处。远端模型调用发生在用户选定服务并确认该批输入之后。任何切换接收服务的操作都由用户选择。

长会话按消息边界分段，保留引用后汇总，并检查成稿中的引用能在包内定位。逐会话记录「复用、已生成、待生成、失败」和输入指纹。断网、超时、限额、CLI 不可用或用户取消生成时，原文仍可完成归档，结果页可单独补生成失败项。报告区分「原文导出完整」和「接手稿全部就绪」。Key、授权头及包含凭据的 URL 排除在迁移包、接手稿和日志之外。

进度页的「停止生成接手稿，继续备份」独立于「取消任务」。已完成的稿件可继续随包保存，未完成的稿件标为待生成。自定义服务已发出的请求在返回或超时后结束，后续请求随即停止。超长单条消息拆分时，每段都带同一个原文编号和行号范围。

## 包格式、兼容与恢复

- 新清单登记格式版本、包用途、来源、项目实体和引用、文件及哈希、Codex 脱敏规则版本、Claude 阅读内容和生成状态。能力由客户端依据实际内容计算，包内声明不能自行开启原生写入。原始保全使用独立文件及用途标记，恢复密钥单独保管。
- 新客户端继续读取现有 ZIP、加密保全和历史差异归档。旧包中的 Codex 可在独立副本转换并通过新版检查后进入原生导入。Claude 可从旧包只读提取可用历史。未知格式给出可读范围及阻止原因。新格式使用独立版本标识，旧客户端会提示格式不支持。
- 打开 `conversation-migration-1` 旧包后，勾选 Codex 会话并通过「新建备份」另存新版迁移包。转换从旧包提取选中会话相关的数据库行和日志。分页索引引用包内缺失的 rollout 时，会在目标预览说明阻止原因。旧 Claude 日志没有 Desktop 索引时，也可另存为主会话和子代理阅读版。
- 在线导出记录扫描截止点和逐文件、逐库快照范围，客户端可继续运行。导出前分别估计迁移包、私人保全和临时空间，缓存位置可选移动硬盘。正式替换旧包时，先在并列位置生成，再回读全部对象、验证密钥及历史引用。旧版本独有资料先单独保全。具体哪一份私人包要替换，由该次导出操作指定。
- 备份库中同一总目录下的两份已完成备份，可从新版结果选择「设为指定备份的当前版本」。新版的迁移 ZIP、阅读引用和加密保全回读通过后，原目录整份留在同盘的旧版目录，新版接管选定目录。中断时可从同一入口重试，客户端根据切换记录核对并恢复。
- 目标端先选资料和项目映射，再预览冲突与所需空间。写入前完整备份实际受影响的目标资料并校验，在独立副本处理，复核目标自预览后没有变化，最后发布。中断后依据回执继续或回退，恢复记录保护导入后用户新增、修改的内容。浏览和初步预览使用只读快照。准备写入时，提示用户关闭将要写入的 Codex 或 DSH 客户端并重新核对目标状态。
- 验收分别记录文件回读、原生客户端可见性、真实账号和模型续聊。目标端的登录、组织权限、模型供应商及格式兼容性以实际验证为准。

| --- | --- | --- |
| 1 · 导入边界和 Codex 脱敏 | 混合包预览按三种来源给出操作，可导出一条经处理的 Codex 会话。 | 在合成目录、继承日志、数据库行和派生记录植入虚构账号标识，可迁移包及报告无已识别值。会话链、分页定位和正文回读正确，原始保全解密后与快照相符。GUI、批量入口、旧计划和侧栏入口均拒绝向 Claude 资料目录写入。同包的 Codex、DSH 可逐条选择。 |
| 2 · 每项目选一次 | 项目清单显示关联软件、大小、工作树状态和三个处理选项，新机按项目映射。 | 三软件共用的工作文件只有一份对象，三方引用都可解析。短路径项目可带走，同名独立项目及不同工作树可区分。使用本地测试仓库验证指定提交、未推送提交、未跟踪文件、差异冲突和离线改选。 |

## Mac 构建交接

构建方可在 macOS 上解压源码包，使用 Python 3.12 安装锁定的构建依赖，选择一个全新的产物目录。

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements-build.txt
.venv/bin/python tools/build_macos_release.py --dist release --work build/macos
```

成功结果在 `release` 中包含 DMG、SHA-256 文件和合成验收报告。构建入口先跑测试，然后验证应用签名、检查 DMG、挂载为只读并启动镜像内的应用。镜像验收需要确认 Codex 和 DSH 合成导入与撤销、独立文件恢复以及 Claude 历史只读加载。镜像在全部检查通过后才写到产物目录。此流程的签名为本地临时签名，公开分发的开发者签名和公证需由发布方另行配置。

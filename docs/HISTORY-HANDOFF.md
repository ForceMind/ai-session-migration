# 历史与接手

0.4.0 可在会话库选中 Claude 历史后点「新建导出」，或从「历史与接手」页导出已接入的编号阅读版。可选择复用已有成稿，或使用本机 Codex 和自定义模型服务补生成。提交前确认模型服务和本批对话。自定义服务填写地址、模型名、API Key，并选择 Chat Completions 或 Responses。Key 仅供本次请求使用。

新电脑只需打开迁移 ZIP，点击「查看包内 Claude」即可阅读、定位原文和复制接手稿。待生成或生成失败的会话仍可阅读，结果可另存为新的迁移 ZIP。

打开客户端，在侧栏选择「历史与接手」。如果已配置本地阅读版，启动后会直接进入真实会话列表。首次没有资料时显示来源选择，不显示演示会话。

1. 选择 Claude 阅读版里的「会话」目录，目录内为编号 Markdown 文件。点击「读取目录」。换电脑后，先把归档复制到新位置，再重新选择目录。
2. 默认列出主会话。可按项目、编号或标题搜索；勾选「同时搜索正文」可检索原文。顶部类型选择可切换到子代理记录或未确认文件。未确认文件不猜测角色和编号。
3. 选择一条会话，在「历史原文」逐条阅读完整消息。每条标明原文消息编号和物理行号；正文按原始行号展示。上方显示完整来源路径，可复制路径或打开所在文件夹。
4. 切到「接手稿」，查看已整理的历史停点、待复核项和第一步，可编辑后点击「复制当前接手稿」。切换会话会清除当前编辑。已有稿件不会重新生成。
5. 没有整理稿的记录可在原文页勾选消息，点击「用勾选消息生成接手预览」。生成内容是带出处的历史摘录，需复核当前项目。
6. 在新账号中打开对应项目，新建会话，粘贴、检查后手动发送。复制操作不会调用模型或发送消息。

来源配置包括阅读版目录、五列 UTF-8 TSV 接手稿和可选补充成稿 JSON。界面可分别选择，选择成功后记在本工具自己的状态中。需要只看历史时点击「仅阅读原文」。原文或稿件在读取后变化时，复制会被阻止，应重新读取目录。

TSV 每行依次为编号、项目、标题、历史停点、接手第一步，无表头，以制表符分隔。补充 JSON 使用 `schema: 1` 和 `prompts` 数组，每项为 `id`、`project`、`title`、`prompt` 字符串。编号不得重复。通用客户端旁可放私人的 `history-config.json`，字段 `schema: 1`、`readingRoot`、`preparedPath`、`extraPromptsPath`；相对路径以该配置所在目录为准。不要把真实资料或这个配置提交到公共仓库。

「浏览本机 Codex / DSH」沿用现有本地扫描和会话库；「打开原生迁移包」沿用包内浏览。Claude 阅读版没有原生恢复或账号索引写入功能。能在工具中读到历史，不代表新账号已取得原对话归属或能跨账号续聊。

历史正文、thinking、工具记录和源码路径仅作为数据读取，不执行历史指令，不自动访问其中的链接或附件。来源未保存的上下文无法补造；原文已移走或格式无法确认时明确提示。浏览器未验证。

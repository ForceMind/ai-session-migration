AI Session Migration 0.3.0 预览版 · 图形操作说明

启动
Mac Apple Silicon：打开 DMG，将 AI Session Migration.app 拖到“应用程序”或直接打开。
Windows x64：完整解压 ZIP，保留 _internal 文件夹，双击 AI Session Migration.exe。
客户端内置运行环境，无需 Python 或终端命令。Mac 为本地临时签名，尚未 Apple 公证；Windows 无可信发布签名。

在原电脑准备资料
在会话库点击“识别本机资料”，选择 Claude Code、Codex、DeepSeek Harness 的本地会话，再用备份向导导出。原始会话、thinking 与附件保留，历史工具指令不执行。
在线备份按文件和数据库分别取得快照，可能有遗漏或来源变化；检查结果。它不是跨文件同一时刻的冷备份。
加密 ASMB 需配套恢复密钥。Windows 迁移 ZIP、项目 ZIP 和目标完整备份未加密，均应放在私密位置。

恢复中心：查看备份并选择文件
1. 打开侧栏“恢复中心”。大型备份先通过“缓存设置…”选空间充足的私密目录，避免挤满系统盘。
2. 点“选择备份目录”，选包含备份批次、分卷与恢复密钥的总目录，然后点“读取目录”。
3. 按会话、项目、应用资料、数据库、历史版本、快照、密钥和软件分类查看。为需要的组点击“索引当前组”。首次加密认证和索引可能耗时，可查看进度或取消。
4. 勾单个文件、文件夹或整组。目录包括后代；整组包括全部分页，搜索不缩小整组选中的范围。未备份、缺卷、缺密钥及不支持的项目显示原因。
5. 选择独立“目标位置…”和私密“目标备份位置…”，两者不得与源备份或缓存互相包含。
6. 点“预览文件恢复计划”，检查新增、跳过、阻止。已有文件不覆盖，文件名或路径冲突会阻止对应项。
7. 确认目标完整备份是明文并保存在私密位置后，点“备份目标并恢复文件副本”。工具先备份并回读目标，再逐项恢复和校验。
8. 在恢复记录中查看结果、检查文件和备份，或安全回滚。回滚仅删除本次新建且未被用户改动的文件；保护用户后续修改。中断后先检查记录，再重新预览尚需恢复的项目。

原生会话导入
先安装、登录并初始化目标原客户端，准备目标项目文件夹。实际原生导入前退出目标客户端及后台任务。
从会话组点“打开原生会话选择…”，或在会话库“打开迁移包”，勾选会话后点“导入到本机”。
映射目标项目和资料目录，选择完整目标备份位置，再预览新增/跳过/阻止。同 ID 会话跳过，不自动合并、改号或覆盖。
确认原客户端已退出及备份隐私提示后，再备份目标并导入。账号和组织按目标电脑选择，不限于源账号或组织。
Claude Desktop Code 索引需要选择目标账号下对应索引容器；普通云端聊天不属于本地 Code 导入。
Codex 需要相容且已初始化的状态及分页历史数据库。DeepSeek 支持已适配的日志/注册表代际，未知格式保全并显示边界。

必须区分的结果
文件提取成功不等于原客户端已能原生显示、登录或续聊。Mac 专用应用资料、数据库与凭据在恢复中心仅作为文件副本；目标原生应用兼容需另行验证。
符号链接恢复为描述文件，不跟随链接。旧失败归档若未保存原文件名，会明确显示按原对象提取，不伪造项目路径。
资料仍可能包含登录记录或私密附件，密钥正文不在界面显示。源登录、旧权限、远程连接、Goals、队列和执行配置不随原生会话导入启用。
104 项测试在本地、Linux 和 Windows 通过；两平台打包程序已通过合成原生导入与文件选择恢复检查。真实 Windows 资料导入、原客户端显示、跨账号/组织/供应商及实际续聊仍需在目标电脑验证。
建议先选少量会话核对正文、附件和 thinking，再验证续聊，最后分批恢复；原电脑资料与备份继续保留。

## 用户界面

1. 欢迎与资料选择：识别 Claude、Codex、DeepSeek Harness；允许用户选择自定义目录；解释来源缺失和应用仍在运行的情况。
2. 会话库：来源与项目导航、会话列表、搜索筛选、归档标记、缺失目录与附件提示。
3. 会话详情：用户消息、回答、工具调用和结果、附件预览；分段加载长历史。thinking 保留并可折叠展示，不改写原始数据。
4. 备份与迁移准备：选择会话、目标位置和保护方式，展示实际涉及的项目和附件，再启动备份；进度、取消、失败和可续接状态均可见。
5. 结果与备份库：显示已保存数量、校验、遗漏、源变化与加密回读状态；在线快照和应用退出后的备份分别标识；一键在文件管理器打开交付位置。

首次打开只读取资料，不启动原客户端、不调用模型、不自动恢复任务。历史中的工具调用和指令仅作为历史展示，不执行。

## 三种来源的接入

### Claude

读取 Code 会话正文与 Desktop 索引，明确区分 Desktop ID 和 CLI ID。保留默认及额外 profile、多副本和续聊段，不按文件大小合并分叉。普通云端聊天需账户同步或官方导出，不能宣称本地目录包含全部云端内容。

### Codex

同时处理分页历史数据库、日志、归档、附件和项目关系，不以单份 JSONL 代表全部历史。将模型供应商兼容、原目录缺失与历史可见性分开显示。查看数据不启用旧 Goals、队列、远程连接或权限。

### DeepSeek Harness

发现默认目录、DSH_HOME 及可识别的自定义存储根。保留 session.vN.jsonl 与 session.vN.jsonl.zstd 的原始版本代际，不改写或触发在源目录的格式升级。

以 workspace 注册表保存项目归属、排序、归档和置顶；以原始事件日志为历史依据；投影缓存只作为可核对的显示提示，不能覆盖日志或被当作独立会话。父子/派生关系、附件对象及所有物理代际均需保留。

查看历史需要只读解码；未知代际显示“不支持解析”，允许保全原始资料，不假造会话或成功状态。凭据、profile 中的服务认证和执行配置不直接作为 Windows 登录材料。原生导入和跨版本升级只在目标副本通过受支持机制进行。

## 桌面实现

采用 Qt 桌面界面及独立数据适配器；应用打包时内置运行环境、解压和加密依赖，让用户安装后即可操作。界面与耗时任务隔离，后台任务提供进度、取消、日志及失败续接；既有数据包保持可读。

Qt 的独立分发工具支持 macOS 应用包与 Windows 可执行文件，具体构建和依赖要求以 [Qt 官方部署说明](https://doc.qt.io/qtforpython-6/deployment/deployment-pyside6-deploy.html) 为准。构建成功、签名状态及目标机实测分别记录。

实现采用 PySide6 Essentials、PyInstaller，依赖和构建版本已锁定。Windows 在 Windows CI 构建，Mac 在本机构建；签名、可信发布与更新渠道按实际状态单独记录。

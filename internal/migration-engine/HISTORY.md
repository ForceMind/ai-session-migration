## v0.5.0 本地备份与迁移包（2026-11-04）

当前获批范围：在原项目新增源资料只读的 Claude/Codex 备份及 Windows 数据打包工具，制作校验过的 Mac 保全备份和便携包；保留现有 thinking 和全部 Mac 资料。Windows 导入/续聊、源码推送、网站发布不在本批次执行范围。主智能体独立完成。

实现：独立 Node 入口与 Python 标准库实现；计划固定来源及输出排除，发现相关项目，SQLite backup 纳入 WAL，流式归档与逐文件哈希校验，加密保全备份及实际解密回读，Windows 只读校验入口。默认不恢复应用；在线快照明确记录变化并要求离开 Mac 前另做最终冷备份。旧维护命令与 v0.4.1 计划/备份协议保持原实现。

进度：原有49项测试通过；新增13项迁移测试通过，覆盖活动日志压缩期间继续增长、缺少WAL/SHM的源库、独占数据库稳定文件集以及失败批次校验续接。前批在线捕获因真实活动日志/独占缓存库停止，未标记成功；已定位原因并完成针对性真实只读验证。当前新批次已校验复用278943项记录并继续捕获。目标置于用户指定私有目录下，真实清单/密钥/报告不加入源码仓库。Windows导入、真实模型续聊和最终冷备份未执行。

本轮在线交付完成：保全归档768195个文件、72373261103字节；Windows便携归档439219个文件、51653613261字节。两份归档逐文件SHA-256校验和加密后实际解密回读比对通过，正式文件已fsync。工具独立分发包及Node/Python入口通过检查，本地62项测试通过。原始Mac应用资料与现有thinking未改写；未提交、推送或发布，Windows未导入及续聊验证。

验收边界：在线捕获期间记录498项源变化；一个IndexedDB缓存blob捕获前已消失，未纳入。前面失败批次的数据与日志默认保留，其中有未加密的临时归档，不作为正式交付；真实路径及取走清单见本机私有交付报告。用户明确选择暂缓最终冷备份，先交付工具和在线包；提供独立终端的最终备份入口，后续须应用退出后再执行。此状态不等于全应用原子快照或最终冷备份完成。

# UI Design 01

当前产物是桌面客户端的**视觉稿与可点击设计预览**，不是已接入真实资料的客户端或安装包。所有会话、附件、路径、数量和任务结果均为示例；不读取本机资料、不调用模型、不创建备份，不修改原始会话或 thinking。

打开 `ui-preview.html` 查看可点击设计，相关样式和图标均随包提供，不加载外部资源。预览默认显示会话库；页面下方可切换到首次启动设计。用户不需要执行任何脚本或命令。

## 视觉系统

- 深石墨色工作区、低对比边框、薄荷色主操作；琥珀色用于需要关注的状态。
- 左侧导航、中间会话列表、右侧详情，保留桌面工具的持续上下文。
- Claude、Codex、DeepSeek Harness 有独立的来源标识；标识为设计用图形，不代表官方授权。
- 主操作保持稳定：在会话库创建备份，进入向导后按选择内容、保存与保护、确认并开始推进。
- 主要内容采用系统字体。会话正文强调可读性，来源、时间和状态降低视觉权重。
- 以 1280×800 及以上桌面窗口为主要目标；macOS 和 Windows 客户端最终使用各自的窗口装饰。

## 可点击范围

首次启动、会话库、来源管理、迁移清单、备份向导、模拟进度、备份库与结果页。

可以切换来源和项目、搜索筛选、选择或标记会话、预览示例附件、查看未知格式和缺失目录、单独保存演示密钥、取消模拟任务，或切换完整通过/有遗漏/失败可恢复的结果设计。

标记与迁移清单属于本工具内的管理。移出清单不删除源会话；设计稿不提供修改原客户端归档、删除历史或改写 thinking 的操作。详情是历史查看器，没有发送新消息的输入框。

## 关键状态

- 没有结果：保留搜索条件，提供清除筛选入口。
- 原目录缺失：允许查看已保存历史，并提示目标机重新关联项目。
- 格式待确认：允许保全原始文件，正文暂不假造解析。
- 密钥未单独保存：备份向导不能进入确认阶段。
- 来源仍运行：清楚标记在线快照，不自动关闭应用或终止任务。
- 结果有遗漏：使用琥珀色“完成，需关注”，列出具体遗漏。
- 校验未完成或失败：不显示文件已成功保存，保留继续处理入口。
- Windows 导入与真实续聊：单独显示为待目标机验证。

## 本轮检查

已检查 JavaScript 语法、离线资源引用、SVG 结构及模拟状态逻辑；静态 PNG 已进行图像检查。模拟逻辑检查使用 DOM 替身，不能代替真实浏览器交互验收。**浏览器未验证，原生 GUI 尚未实现。**

后续沿已批准的 GUI 方案，将确认后的视觉与操作流程落入可双击运行的客户端，再接入三来源的只读解析、备份和校验。Windows 导入及续聊验证继续等待目标机。
